# Lab 6: Message Queuing with SQS

## Overview

In this lab, you'll learn how to:
1. Create an SQS queue
2. Modify the Kotlin application to send messages
3. Create a Lambda function to process messages
4. Monitor message processing

## Key Concepts

### Amazon SQS
- Message queuing service
- Decoupled architecture
- Message retention and visibility
- Dead-letter queues

### AWS Lambda
- Serverless compute
- Event-driven architecture
- Function scaling
- CloudWatch integration
